# Sistema Inventario Castores

Sistema de inventario desarrollado como prueba técnica utilizando Spring Boot, Thymeleaf y SQL Server.

# Tecnologías utilizadas

- Java 17
- Spring Boot 3
- Spring Security
- Thymeleaf
- Bootstrap 5
- SQL Server Express
- Hibernate / JPA
- Maven

# IDE utilizado

- IntelliJ IDEA Community Edition

# DBMS utilizado

- Microsoft SQL Server Express

# Pasos para ejecutar la aplicación

## 1. Clonar repositorio

git clone URL_REPOSITORIO

## 2. Crear base de datos

Ejecutar script:

SCRIPTS/database.sql

## 3. Configurar application.properties

Actualizar:

- usuario SQL Server
- password SQL Server
- nombre servidor SQL Server

## 4. Ejecutar proyecto

Desde IntelliJ IDEA:

Shift + F10
